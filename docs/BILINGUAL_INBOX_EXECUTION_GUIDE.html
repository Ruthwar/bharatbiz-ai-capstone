Quick start and current limitations

Six steps for every example

  1. Select the specified Sender and Language.
  2. Enter the suggested Conversation ID.
  3. Paste either the English or Hinglish message.
  4. Click Send for processing.
  5. For a clarification reply, retain the same sender and Conversation ID.
  6. For an independent example or independent market report, use a new Conversation ID.
Editable intake versus full scenario: Send for processing handles only the visible message and persistent intake history. Run full scenario applies the fixture's explicit demand, supplier, cash, stock, history and observation overlays.
Verified LLM extraction limitation: Current LLM mode can omit demand percentage, physical count and complaint order reference. Multi-turn SCN-002, SCN-005 and SCN-006 can therefore repeat the same question until human triage. The documented sequences complete through the deterministic rules path.
Fixture-only behaviour: Plain intake does not turn SCN-004 payment wording into a cash-receipt overlay. SCN-008 requires an explicit combined-disruption fixture and routes editable intake to human triage. Use Run full scenario for their canonical operational outcomes.
