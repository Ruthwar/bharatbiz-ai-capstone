## Purpose and scope

This procedure explains how the warehouse team performs stock rotation and picking for the Beverage category. It applies to the SKUs listed in the document metadata and to any pack size derived from them.

## Steps

1. Mark short picks with the reason code instead of silently reducing the quantity.
2. Confirm the pick quantity against reserved stock before releasing the line.
3. Return unpicked units to their recorded location before the shift closes.

## Records

The operator records the state version, the quantity, the reason code and the approver for every exception. Records are retained with the intake or dispatch reference so a reviewer can reconstruct the action.

## Escalation

If the steps cannot be completed against the current state version, the operator stops and raises the case for triage. The operator does not estimate a quantity, reallocate reserved stock or release recalled stock to keep the workflow moving.
