# Synthetic dataset dictionary

Generated by `scripts/generate_synthetic_data.py`; all entities and events are fictional. Reproducible with a fixed seed. Currency is exact decimal rupees with two decimal places; quantities use the explicit `unit`/`base_unit` field. Dates are ISO 8601; timestamps include +05:30. `messages.jsonl` contains 1,000 labelled synthetic examples; `events.jsonl` has corresponding evidence-linked event annotations. Keep both separate from any permissioned pilot data. `scenarios.csv/json` provide eight repeatable cases. Supplier offers are valid only for listed supplier-SKU rows. No value represents verified local prices or business activity.

Supplier and retailer rows carry fictional trade names (`supplier_name`, `retailer_name`, `shop_type`, locality `area`). Names are display labels only; `supplier_id` and `retailer_id` remain the internal join keys used by orders, deliveries, facts, plans and review records. Messages quote trade names the way a person would write them, while the `entities` annotation stores both the name and the matching ID.

Tables: products, suppliers, retailers, supplier_products, inventory, historical_order_lines, open_orders, supplier_deliveries, cash_ledger, scenarios and messages/events. Stable IDs connect related rows. Unknown source facts must remain unknown.
